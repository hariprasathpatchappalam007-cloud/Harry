The exception occurs at the first database check in ChargeCycleProcessor.ProcessAsync, before the SQL connection is opened. This attempt did not proceed to SME data retrieval, charge calculation, or inserts.

After correcting the setting, restart the service so it reloads the connection string. The worker remembers a failed attempt for that date, so restarting is needed for another attempt; if the SME schedule time has already passed, it should retry on the next poll. Be aware that the corrected run can proceed into database processing. TrustServerCertificate=True skips certificate validation, so use it only where approved; production should use a trusted SQL Server certificate.
